Swap devices: /var/lib/swap (0.0/1024.0 MB). vm.swappiness = 60.
vm.swappiness (0-200 on Linux >= 5.8, default 60) is the relative cost the kernel assigns to swapping anonymous pages versus dropping file-backed page cache when it must reclaim memory. Lower values prefer dropping cache; higher values swap anonymous pages more readily. It does not make the kernel swap when there is no memory pressure. Swap *used* alone is not a problem; sustained swap-in/out traffic is.
